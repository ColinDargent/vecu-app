Jetons MCP

Un jeton MCP laisse un agent (Claude Code, une routine) lire et écrire le second cerveau en votre nom, sans qu'un poste soit allumé. Il ne peut jamais faire plus que ce que vous pouvez faire vous-même, et son plafond peut le restreindre davantage.

Voici le jeton. Il ne sera plus jamais affiché.

Copiez-le maintenant : le serveur n'en garde qu'une empreinte, il ne peut pas vous le remontrer. Si vous le perdez, révoquez-le et créez-en un autre.

{{.Clair}}

Pour le brancher sur Claude Code, coller le jeton à la place de LE_JETON dans cette commande :

claude mcp add --transport http vecu "https://VOTRE-SERVEUR/mcp" --header "Authorization: Bearer LE_JETON"

Le jeton n'est pas mis dans la commande ci-dessus à dessein : une commande collée telle quelle se retrouve dans l'historique du terminal, où la révocation ne va pas la chercher.
